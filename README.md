# HomeOrOffice
This application helps you track how many days you were in the office, working from home, or on a business trip. 

It opens automatically when you start your computer and asks where you are. This answer is saved in an SQLite database. 
Clicking on a date in the calendar shows where you worked on that day. 
You can also change the selection for this day if you need to.
If you click the 'Export data' button, you can see how many days you have spent in each year. 
You can also export the yearly information into an Excel file. In the Excel file, you can see every single day and where you spent it.
